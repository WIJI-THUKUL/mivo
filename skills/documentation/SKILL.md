# Documentation
- README sections: what it is (1-2 lines), install, quick start with a runnable example, configuration, commands/API, troubleshooting, license.
- Examples must be copy-pasteable and tested by actually running them.
- Docstrings: say what and why, document parameters, return value and raised errors; skip comments that restate the code.
- Keep docs next to the code and update them in the same change as the behavior they describe.
